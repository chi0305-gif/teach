## RWD 響應式設計

同一個網頁會依照螢幕大小自動調整版面，不需要另外做手機版。

| 裝置 | 版面 |
| --- | --- |
| 電腦、平板橫拿（寬度 801px 以上） | 左上品牌、右側牌卡清單、卡片浮在畫面中間，下方是功能列 |
| 平板直拿（寬度 601～800px） | 品牌與工具列合併成上方一列，卡片與清單改成可以上下拖曳的抽屜 |
| 手機（寬度 600px 以下） | 卡片從下方滑出，按鈕加大方便手指點按 |
| 手機橫拿（高度 500px 以下） | 壓縮上方標題，保留最多的畫面給 3D 島嶼 |

其他細節：

- 依照實際看得到的螢幕高度調整，避免平板下方的功能列被瀏覽器網址列擋住。
- 支援 iPhone／iPad 的瀏海與圓角安全區域（`safe-area-inset`）。
- 觸控裝置的按鈕至少 44px，方便點按。
- 系統開啟「減少動態效果」時，動畫會自動關閉。

想檢查版面時，可以在網址後面加上 `?debug=1`，畫面上會顯示偵測到的螢幕尺寸。

## PWA：加入主畫面、離線使用

網站是 PWA（漸進式網頁應用程式），可以像 App 一樣安裝到平板或手機的主畫面。

### 怎麼安裝

- **iPad／iPhone（Safari）**：打開網站 → 按「分享」按鈕 → 選「加入主畫面」。
- **Android／Chromebook／電腦（Chrome、Edge）**：按工具列的「📲 安裝」按鈕，或網址列右邊的安裝圖示。

安裝後從主畫面打開，會用全螢幕顯示，沒有網址列，3D 島嶼的畫面更大。

### 離線與更新

- 開過一次網站後，即使網路暫時斷線也能打開。
- 網頁本身採「**先連網拿最新版，連不上才用快取**」，所以老師更新網站後，學生只要連上網路就會看到新版，不用清除快取。
- 學習紀錄如果在斷線時送出，會先存在裝置裡，下次連上網路再自動補送。
- Padlet、YouTube 等外部網站仍需連網才能使用。
- 如果修改了 `sw.js`，或想強制所有裝置清掉舊快取，把 `sw.js` 第一段的 `VERSION = 'v1'` 改成 `'v2'` 即可。

> 嵌在 Google 協作平台裡時，網站一樣正常運作，但不會顯示「安裝」按鈕；要安裝請直接打開網站網址。

## 發布到 GitHub Pages

網站從這個 repository 的 **`main` 分支**自動發布。

### 第一次設定（已完成）

1. 進入 repository → **Settings** → **Pages**。
2. **Source** 選「Deploy from a branch」。
3. **Branch** 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等 1～2 分鐘，網站就會出現在 <https://chi0305-gif.github.io/teach/>。

### 用網頁上傳更新檔案

1. 打開 <https://github.com/chi0305-gif/teach>，確認左上角分支是 `main`。
2. 按 **Add file** → **Upload files**。
3. 把要更新的檔案（例如 `index.html`、`index-程式碼.txt`）拖進來。
   要更新圖示時，先點進 `icons` 資料夾再上傳，檔案才會放在正確位置。
4. 下方填寫修改說明，按 **Commit changes**。
5. 等 1～2 分鐘，重新整理網站就會看到新版。

## 嵌入 Google 協作平台

1. 在 Google 協作平台編輯頁面，選「插入」→「嵌入」。
2. 選「**依網址**」，貼上 `https://chi0305-gif.github.io/teach/`。
3. 選「**完整頁面**」，再把嵌入框拉到整個頁面寬度。

## 學生學習紀錄 → Google 試算表

| 工作表 | 什麼時候寫入 | 欄位 |
| --- | --- | --- |
| 後山厚閱讀 | 學生按下「蓋印章」 | 時間、班級、座號、姓名、主題、單元、出口卡、快問快答一次答對、心情天氣 |
| 柴郡貓思辨卡 | 學生完成四個關卡 | 時間、班級、座號、姓名、冊次、課次、問題、關卡、思辨卡內容 |

### 設定方式

1. 建立一份 Google 試算表 → 「擴充功能」→「Apps Script」。
2. 貼上 `google-apps-script/learning-records.gs` 的全部內容，按「儲存」。
3. 「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 複製結尾是 `/exec` 的網址，填到 `index.html` 裡的 `window.RECORD_ENDPOINT`。

### 注意事項

- 試算表、工作表名稱和第一列標題不要修改。
- 修改 Apps Script 程式後，要到「管理部署作業 → 編輯 → 版本：新版本」重新部署才會生效。
- 瀏覽器同時登入多個 Google 帳號時，打開 `/exec` 網址可能顯示「無法開啟這個檔案」，改用無痕視窗測試即可。
- 試算表裡有學生姓名，請只分享給需要的老師。

## 在自己的電腦上測試

PWA 的離線功能必須透過網址（`http://localhost` 或 `https://`）開啟才會啟動，直接雙擊 `index.html` 只能看畫面。

```bash
python3 -m http.server 8000
```

接著用瀏覽器打開 <http://localhost:8000/>。

## 使用的技術

- 單一 HTML 檔案，不需要編譯或安裝套件。
- [Three.js 0.160](https://threejs.org/)（從 jsDelivr CDN 載入）繪製 3D 島嶼。
- 原生 JavaScript、CSS Grid／Flexbox、CSS 變數與 media queries。
- `localStorage` 保存遊戲進度與印章（只存在學生自己的裝置上）。
- Google Apps Script 接收學習紀錄。
- Service Worker ＋ Web App Manifest 提供 PWA 功能。
